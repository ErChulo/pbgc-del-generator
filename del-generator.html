Welcome

This app writes the DEL — the Data Element Listing — from plan documents. It does not read the documents itself.

How it works, in 5 steps: download the scraper prompt · feed the prompt and the documents to an LLM · upload the JSON the LLM returns · review each field · generate the Word document.

The LLM proposes. The app checks. You decide. Nothing leaves this page — there is no server.

    Help

    What is a DEL?

    A table of all the fields a PBGC case needs, and where each one comes from. It is a wish list — every field the plan could need, not only the ones in the census.

    What does the LLM do?

    It reads the plan documents and finds, for each field, whether the plan needs it, for which groups, and where the concept appears. It returns JSON. It never writes the Word document.

    What if the LLM is wrong?

    You review every field before anything is generated. A wrong value is never used — a missing or ambiguous one is shown to you instead.

    Where do the fields come from?

    The BCV Data Dictionary Complete: all Input fields (220 Input + 51 Input|Calculated). This version covers the template's 56. More groups come later.

    Glossary

    DEL — Data Element Listing. DOPT — Date of Plan Termination. QDRO — Qualified Domestic Relations Order. ARD — Actual Retirement Date. PA_AMB — Prior Administrator's Accrued Monthly Benefit.

    Match ranking

    Each dictionary field, matched to the plan-document verbiage that means the same thing. The score compares the dictionary definition with the matched passage. Highest first.

    The score is a plain count of shared words and phrases — it ranks, it never decides. Check the low scores first. Fields with no match are listed on their own, never dropped.
